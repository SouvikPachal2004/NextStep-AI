# 🚀 Quick Reference - Assessment PDF Upload Feature

## 📍 Where to Upload PDF (Admin)

**Path**: Admin Dashboard → Assessments → Create Assessment → Questions Manager

**Exact Location**: Top section of Questions Manager modal with purple gradient background

**Button**: "Choose File" → Select PDF → "Upload & Parse PDF"

---

## 📍 Where Assessments Appear (User)

**Path**: User Dashboard → Assessments Tab

**Organization**: By category (JavaScript, Python, React, etc.)

**Button**: "Start Assessment" on each assessment card

---

## 📄 PDF Format (Quick)

```
Q1. Question text?
A) Option 1
B) Option 2
C) Option 3
D) Option 4
Answer: A

Q2. Next question?
A) Option A
B) Option B
C) Option C
D) Option D
Answer: B
```

**Rules**: Q1., Q2., etc. | A), B), C), D) | Answer: A

---

## 🎯 Complete Flow

### Admin:
1. Login → Admin Dashboard
2. Assessments → Create Assessment
3. Fill details (Title, **Category**, Difficulty, Duration)
4. Questions Manager opens
5. Upload PDF (top section)
6. Done!

### User:
1. Login → User Dashboard
2. Assessments Tab
3. Find by category
4. Start Assessment
5. Answer 20 questions (one by one)
6. Submit
7. See score + recommendations

---

## 📊 What User Sees After Submission

- **Score**: 85% (17/20 correct)
- **Status**: Passed ✅ or Failed ❌ (80% required)
- **Breakdown**: Correct/Wrong/Time taken
- **Recommendations**: Topics to review
- **Question Review**: Your answer vs correct answer
- **Action**: Retake Assessment button
